# SwarMind manual

[Italiano](../it/README.md) · [Project README](../../../README.md)

SwarMind stress-tests a message before launch: a population of AI agents built from your brief
debates a rebrand, a price, a launch or a crisis statement, and a report sums up the objections and
how the debate moved. It prepares you for objections; it does not predict the market.
